# Travel World Tour Agency Landing

A modern, clean landing page for a travel agency designed to help users discover beautiful destinations across different countries.

## ✨ Features
* **Country Explorer:** Browse various countries and view essential details like language, capital, and local currency.
* **City Highlights:** Discover popular cities with curated, useful travel information for each country.
* **Seamless Navigation:** Easily navigate through detailed country pages.
* **Fully Responsive:** Optimized for all device screen sizes (mobile-first approach).

## 🛠 My Role & Contributions
* **Role:** Frontend Developer (built during high school studies).
* **Implementation:** Transformed design concepts into functional code, handled client-side navigation, ensured mobile responsiveness, and managed deployment via GitHub Pages.

## 🧰 Tech Stack
* **React 18**
* **TypeScript**
* **Tailwind CSS**
